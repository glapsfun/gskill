# hello-gskill

This skill exists so the GSKILL documentation has a real, stable skill to
install. Use it when the user says hello, or asks which skills this project has.

1. Greet the user and mention that this skill was installed by GSKILL.
2. Run `gskill list` and summarize the installed skills, their versions, and the
   agents each one targets.
3. If `gskill` is not on `PATH`, point the user to
   https://glapsfun.github.io/gskill/installation/.
