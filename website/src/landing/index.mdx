## Add, commit, reproduce, verify

<Code code={example} lang="sh" title="Terminal" />

The skill's content lands in your repository next to `skills-lock.json`, so a fresh clone
already has working skills. `gskill install --frozen-lockfile` restores exactly what the
lockfile records, and `gskill project verify` re-hashes it to prove nothing changed.

## Why GSKILL

<CardGrid>
  <Card title="Reproducible installs" icon="seti:lock">
    `skills-lock.json` records what you asked for and what was resolved.
    `--frozen-lockfile` restores exactly, or fails closed.
  </Card>
  <Card title="Verified integrity" icon="approve-check">
    Every install is checked against a recorded content hash, and
    `gskill project verify` re-checks on demand. Skill content is never executed.
  </Card>
  <Card title="Many agents, one copy" icon="puzzle">
    A skill is resolved and stored once, then shared with every agent that targets
    it through symlinks, or copies where links are not supported.
  </Card>
  <Card title="Built for CI" icon="setting">
    Every capability is a CLI command with `--json` output and documented exit codes,
    so pipelines can gate on drift.
  </Card>
</CardGrid>

Supports Claude Code, Codex, Cursor, Antigravity CLI, OpenCode, OpenClaw, and Hermes Agent on
Linux and macOS. See [Supported agents](/gskill/reference/agents/).
